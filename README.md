# DemoPrep desktop

Installers for the DemoPrep live coach. Download the latest version from
[Releases](../../releases/latest), or from the Live Call tab on demoprep.site.

- Windows 10 (2004) or later: `DemoPrep-Setup.exe`
- macOS 13 or later, Apple silicon and Intel: `DemoPrep.dmg`

The app updates itself from this page. Source code is not published here.
